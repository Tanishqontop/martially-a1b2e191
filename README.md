# Martially 🥋🌍

Martially is a global platform that connects **martial arts enthusiasts** with **training centres, dojos, and academies** worldwide.  
Whether you’re a beginner looking to start your journey or an experienced martial artist searching for advanced training, Martially makes discovery, booking, and payment seamless.  

---

## ✨ Features
- 🌍 **Global Directory** – Explore martial arts schools and training centres across the world.  
- 📍 **Location-Based Search** – Find dojos and gyms near you with smart filtering.  
- 🥋 **Styles & Disciplines** – Discover centres by martial art type (Karate, Taekwondo, Jiu-Jitsu, Muay Thai, etc.).  
- ⭐ **Ratings & Reviews** – Read real feedback from students before choosing a place to train.  
- 💳 **Integrated Payments** – Book classes and pay securely through the platform.  
- 📅 **Scheduling System** – Reserve classes and track your training schedule.  
- 🤝 **Community Hub** – Connect with other martial artists and share your journey.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+ recommended)  
- npm or yarn  

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/martially.git

# Navigate to project folder
cd martially

# Install dependencies
npm install

# Start development server
npm run dev
